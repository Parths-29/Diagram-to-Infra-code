# Training scripts directory

This directory contains training scripts and Colab notebooks for the
YOLOv8n object detection model.

## Contents

- `train_yolov8.py` — Standalone training script (Phase 2)
- `notebooks/train_yolov8.ipynb` — Google Colab training notebook (Phase 2)
- `notebooks/evaluate_real.ipynb` — Real eval set evaluation notebook (Phase 3)

## Important

Training requires a GPU and should be run on Google Colab, NOT locally.
See the notebooks for step-by-step instructions.
